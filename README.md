# per.li

rust wasm frontend

Written mainly in HTML, Rust, Go, Python.

## Contents

- `.dockerignore` — a file
- `.parcel-cache` — directory
- `Cargo.lock` — a lock file
- `Cargo.toml` — the Rust crate manifest
- `Dockerfile` — the container build file
- `build.rs` — a Rust file
- `dist` — directory
- `ext` — directory
- `lib` — library code
- `main.py` — a Python file
- `pkg` — directory
- `proto` — directory
- `src` — source code
- `static` — static files

## Build and run

A Rust crate or workspace; its manifest is `Cargo.toml`, so the usual Cargo commands (`cargo build`, `cargo test`) apply.
